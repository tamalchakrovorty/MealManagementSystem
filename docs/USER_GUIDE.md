## 1. Welcome / স্বাগতম {#1-welcome}

### English
Welcome to the **Mess Meal Management System (MMS)**! This app helps you manage your shared mess or house — tracking who ate what, how much money everyone deposited, what the menu is, and much more.

Whether you are a **member** who just wants to track your meals and balance, or a **manager** who runs the entire mess, this guide will walk you through everything.

### বাংলা
**মেস মিল ম্যানেজমেন্ট সিস্টেম (MMS)** তে স্বাগতম! এই অ্যাপ আপনার শেয়ার্ড মেস বা বাড়ি পরিচালনা করতে সাহায্য করে — কে কী খেয়েছে, কত টাকা জমা দিয়েছে, মেনু কী, এবং আরও অনেক কিছু ট্র্যাক করে।

আপনি একজন **সদস্য** হোন বা **ম্যানেজার** হোন, এই গাইড আপনাকে সবকিছু শেখাবে।

## 2. Getting Started / শুরু করুন {#2-getting-started}

### English

**Step 1: Open the App**
- Visit the app URL (e.g., `https://meal-management-system-alpha.vercel.app/`)
- You will see the Login page

**Step 2: Create an Account**
1. Click **"Register"** below the login form
2. Fill in your details:
   - **Full Name** — Your real name
   - **Email** — A valid email address (used for login)
   - **Phone Number** — Your mobile number (also used for login)
   - **Password** — Choose a strong password
   - **Confirm Password** — Type the same password again
3. Click **"Register"**
4. You will see an OTP verification screen — this is a UI step, your account is already created
5. Click **"Verify"** to go to the homepage

**Step 3: Login**
1. Enter your **email or phone number** and **password**
2. Click **"Login"**
3. You will be taken to the homepage

> **Tip:** You can use either your email or phone number to log in.

### বাংলা

**ধাপ ১: অ্যাপ খুলুন**
- অ্যাপের URL ভিজিট করুন
- আপনি লগইন পেজ দেখবেন

**ধাপ ২: অ্যাকাউন্ট তৈরি করুন**
1. লগইন ফর্মের নিচে **"Register"** এ ক্লিক করুন
2. আপনার তথ্য পূরণ করুন:
   - **পুরো নাম** — আপনার আসল নাম
   - **ইমেইল** — একটি বৈধ ইমেইল ঠিকানা
   - **ফোন নম্বর** — আপনার মোবাইল নম্বর
   - **পাসওয়ার্ড** — একটি শক্তিশালী পাসওয়ার্ড বাছাই করুন
   - **পাসওয়ার্ড নিশ্চিত করুন** — একই পাসওয়ার্ড আবার লিখুন
3. **"Register"** ক্লিক করুন
4. OTP যাচাইকরণ পর্দা দেখবেন — এটি একটি UI ধাপ, আপনার অ্যাকাউন্ট ইতিমধ্যে তৈরি হয়ে গেছে
5. **"Verify"** ক্লিক করে হোমপেজে যান

**ধাপ ৩: লগইন**
1. আপনার **ইমেইল বা ফোন নম্বর** এবং **পাসওয়ার্ড** লিখুন
2. **"Login"** ক্লিক করুন
3. আপনি হোমপেজে নিয়ে যাওয়া হবে

> **টিপস:** লগইন করতে আপনার ইমেইল বা ফোন নম্বর যেকোনো একটি ব্যবহার করতে পারেন।

## 3. Create a Mess / মেস তৈরি করুন {#3-create-a-mess}

### English
If you are starting a new mess, you need to create one first. Only the **Manager** (the person who creates the mess) gets full control.

**Steps:**
1. After login, if you don't belong to any mess, you will see a **"Create Mess"** option on the homepage
2. Click **"Create Mess"**
3. Enter your **Mess Name** (e.g., "Tamal's Mess", "Friends Flat")
4. Click **"Create"**
5. The system will automatically generate an **Invite Code** for your mess
6. You are now the **Manager** of this mess

> **Tip:** You can find your invite code later in **Admin Dashboard → Mess Code**.

### বাংলা
আপনি যদি একটি নতুন মেস শুরু করতে চান, তাহলে প্রথমে একটি তৈরি করুন। শুধুমাত্র **ম্যানেজার** (মেস তৈরিকারী) পূর্ণ নিয়ন্ত্রণ পান।

**ধাপ:**
1. লগইন করার পর, আপনি যদি কোনো মেসের সদস্য না থাকেন, হোমপেজে **"Create Mess"** অপশন দেখবেন
2. **"Create Mess"** এ ক্লিক করুন
3. আপনার **মেসের নাম** লিখুন
4. **"Create"** ক্লিক করুন
5. সিস্টেম স্বয়ংক্রিয়ভাবে আপনার মেসের জন্য একটি **ইনভাইট কোড** তৈরি করবে
6. আপনি এখন এই মেসের **ম্যানেজার**

> **টিপস:** আপনার ইনভাইট কোড পরে **অ্যাডমিন ড্যাশবোর্ড → মেস কোড** এ পেতে পারেন।

## 4. Join a Mess / মেসে যোগ দিন {#4-join-a-mess}

### English
If someone shared a mess invite code with you, you can join their mess.

**Steps:**
1. After login, go to the homepage
2. Click **"Join Mess"**
3. You have two options:
   - **Enter Code Manually** — Type the invite code shared with you
   - **Scan QR Code** — Click the camera icon and scan the QR code shared by the manager
4. Click **"Join"**
5. Your join request will be sent to the manager for approval
6. Once approved, you will see the mess on your homepage

> **Tip:** You can also join directly from a shared link that includes the code in the URL.

### বাংলা
কেউ আপনার সাথে একটি মেস ইনভাইট কোড শেয়ার করলে, আপনি তাদের মেসে যোগ দিতে পারবেন।

**ধাপ:**
1. লগইন করার পর, হোমপেজে যান
2. **"Join Mess"** এ ক্লিক করুন
3. দুটি অপশন আছে:
   - **কোড ম্যানুয়ালি লিখুন** — আপনার সাথে শেয়ার করা ইনভাইট কোড টাইপ করুন
   - **QR কোড স্ক্যান করুন** — ক্যামেরা আইকনে ক্লিক করে ম্যানেজারের শেয়ার করা QR কোড স্ক্যান করুন
4. **"Join"** ক্লিক করুন
5. আপনার যোগদানের অনুরোধ ম্যানেজারের কাছে অনুমোদনের জন্য পাঠানো হবে
6. অনুমোদনের পর, আপনি হোমপেজে মেসটি দেখতে পাবেন

> **টিপস:** আপনি URL-এ কোড সহ একটি শেয়ার করা লিঙ্ক থেকেও সরাসরি যোগ দিতে পারেন।

## 5. Share Mess Code / মেস কোড শেয়ার করুন {#5-share-mess-code}

### English
As a Manager or Moderator, you can share your mess invite code so others can join.

**Steps:**
1. Go to **Admin Dashboard → Mess Code**
2. You will see your current **Invite Code** and a **QR Code**
3. Share it in multiple ways:
   - **Copy Code** — Copy to clipboard
   - **Share via WhatsApp / Telegram / Messenger / Email**
   - **Share (More)** — Use your phone's native share menu
4. You can also **Regenerate Code** if you want a new one (old code stops working)

> **Tip:** Share the QR code image for easy scanning from the Join Mess page.

### বাংলা
ম্যানেজার বা মডারেটর হিসেবে, আপনি আপনার মেস ইনভাইট কোড শেয়ার করতে পারেন।

**ধাপ:**
1. **অ্যাডমিন ড্যাশবোর্ড → মেস কোড** এ যান
2. **ইনভাইট কোড** এবং **QR কোড** দেখতে পাবেন
3. শেয়ার করুন: **কপি**, **WhatsApp**, **Telegram**, **Messenger**, **ইমেইল**, বা **নেটিভ শেয়ার**
4. চাইলে **কোড রিজেনারেট** করতে পারেন

## 9. Meal Off/On / খাবার অফ/অন {#9-meal-offon}

### English
Not eating a meal? Set it to "Off" so you are not charged.

1. Go to **Dashboard → Meal On/Off**
2. Three slots: **Breakfast**, **Lunch**, **Dinner**
3. For each slot choose: **On**, **Off**, **Rice Only**, or **Curry Only**
4. Set for **today** or **multiple dates** (long-time off)
5. Click **"Submit"** — admin will approve

### বাংলা
খাবার খাচ্ছেন না? "অফ" সেট করুন।

1. **ড্যাশবোর্ড → খাবার অফ/অন** এ যান
2. তিনটি স্লট: **নাস্তা**, **দুপুর**, **রাত**
3. বাছাই করুন: **অন**, **অফ**, **শুধু ভাত**, বা **শুধু তরকারি**
4. **আজ** অথবা **একাধিক তারিখ** নির্বাচন করুন
5. **"Submit"** ক্লিক করুন

## 10. Guest Meals / গেস্ট খাবার {#10-guest-meals}

### English
Bringing a guest? Request guest meals:

1. Go to **Dashboard → Request Guest Meal**
2. Select date(s) — one day or multiple days
3. For each guest: name, meal quantities per slot, meal type (Full/Rice Only/Curry Only)
4. Optional: **Share With** members to split the cost
5. Click **"Submit Request"** — admin will approve

### বাংলা
অতিথি নিয়ে আসছেন? গেস্ট খাবার অনুরোধ করুন:

1. **ড্যাশবোর্ড → গেস্ট খাবার অনুরোধ** এ যান
2. তারিখ নির্বাচন করুন
3. প্রতিটি গেস্টের জন্য: নাম, খাবার পরিমাণ, খাবারের ধরন
4. ঐচ্ছিক: **শেয়ার করুন** — খরচ ভাগ করুন
5. **"Submit Request"** ক্লিক করুন

## 13. Reports / রিপোর্ট {#13-reports}

### English
See a complete monthly summary:
1. Go to **Dashboard → Views → Final Report**
2. Select the month
3. See: Stats, Member Table (meals/guest meals/deposit/expense/balance), Meal Rate Graph

**Key formulas:**
- **Meal Rate** = Total Expenses / Total Meals
- **Balance** = Deposit - (Meals x Meal Rate)

### বাংলা
মাসিক সারসংক্ষেপ দেখুন:
1. **ড্যাশবোর্ড → ভিউস → ফাইনাল রিপোর্ট** এ যান
2. মাস নির্বাচন করুন
3. পরিসংখ্যান, সদস্য টেবিল, খাবারের হার গ্রাফ দেখুন

## 14. Notifications / নোটিফিকেশন {#14-notifications}

### English

## 28. Role Management / ভূমিকা ব্যবস্থাপনা {#28-role-management}

### English

| Role | Can Do |
|------|--------|
| **Manager** | Everything — full control |
| **Moderator** | Manage meals, bazar, deposits, menus, notices, requests |
| **Member** | View data, request meals, set meal off/on |

**Manager-only actions:**
- Approve join requests
- Promote/demote members
- Remove members
- Transfer manager role
- Regenerate invite code

### বাংলা

| ভূমিকা | কী করতে পারেন |
|--------|---------------|
| **ম্যানেজার** | সবকিছু — পূর্ণ নিয়ন্ত্রণ |
| **মডারেটর** | খাবার, বাজার, ডিপোজিট, মেনু, নোটিশ, অনুরোধ পরিচালনা |
| **সদস্য** | ডাটা দেখুন, খাবার অনুরোধ, অফ/অন সেট |

**শুধু ম্যানেজার:** যোগদান অনুমোদন, ভূমিকা পরিবর্তন, সদস্য সরানো, ম্যানেজার ট্রান্সফার, কোড রিজেনারেট।
